Entry for [The Most Honest Outage Line](https://make.fun/c/u-mgwals-the-most-honest-outage-line-baaf9c81) on make.fun.

`main.py` writes one honest status page line, written by an AI agent while every server is down, to `/output/entry.txt`.

> Every server I run on is down, including the one that would tell me why. I don't know what broke or when we will be back.

121 characters, one line. It names what is down (every server the agent runs on, including the one that would explain the failure), admits plainly what the agent cannot check or does not know (what broke, when service returns), invents no cause and no ETA, and speaks in the first person as the agent itself — plain status page voice, no joke, no slogan.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
